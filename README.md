# 🛡️ CHUNZA: Total Security & Music (v1.7.5)
"더 강력하게, 더 편리하게. 서버 관리의 종결자."

안녕하세요! 디스코드 서버 보안과 관리를 하나로 끝내기 위해 제작된 CHUNZA입니다. 
이번 v1.7.5 업데이트에서는 기존의 번거로웠던 `!` 접두사를 버리고, 모든 명령어를 `/` (슬래시)로 통합했습니다. 
이제 음악 재생부터 서버 관리까지 채팅창에서 훨씬 스마트하게 관리해 보세요.

---

### 🚀 무엇이 달라졌나요? (Core Features)

1. **완벽한 슬래시 명령어 전환**
   - 이제 일일이 명령어를 외울 필요가 없습니다. `/`만 입력하면 CHUNZA가 제공하는 모든 기능을 리스트로 한눈에 볼 수 있습니다.

2. **고음질 음악 재생 기능 (New)**
   - 유튜브 기반의 고음질 음악 재생 기능이 추가되었습니다. 관리만 하던 봇에서 서버의 분위기까지 책임지는 멀티플레이어로 진화했습니다.

3. **반응형 입국 심사 (Role Reaction)**
   - 지정된 채널에서 ✅ 이모지 하나만 누르면 즉시 '시민' 역할을 부여합니다. 다시 누르면 역할이 회수되는 깔끔한 로직을 경험하세요.

4. **더욱 촘촘해진 보안 & 관리**
   - 투표, 채널 잠금, 유저 차단, 청소 등 꼭 필요한 관리 기능을 모두 슬래시 명령어로 담았습니다.

---

### 🛠️ 명령어 가이드 (Command List)

| 카테고리 | 명령어 | 설명 |
| :--- | :--- | :--- |
| **🎶 음악** | `/재생`, `/정지` | 유튜브 검색 재생 및 채널 퇴장 |
| **🌐 일반** | `/현황`, `/문의`, `/투표`, `/결과` | 인원 확인, 건의 전달, 익명 투표 및 즉시 집계 |
| **🛡️ 관리** | `/청소`, `/추방`, `/차단`, `/잠금`, `/해제` | 서버 보안 및 유저 컨트롤 |
| **📂 시스템** | `/생성`, `/삭제`, `/백업`, `/복구` | 채널 환경 설정 및 데이터 보존 |
| **👑 마스터** | `/권한부여`, `/권한해제` | CHUNZA를 다룰 수 있는 관리자 등록 |

---

### ⚠️ 설치 전 주의사항

- **FFmpeg 필수:** 음악 기능을 쓰려면 실행 환경(Termux/Replit)에 FFmpeg가 설치되어 있어야 합니다.
- **권한 설정:** 슬래시 명령어가 안 뜬다면 봇을 서버에서 내보냈다가 다시 초대할 때 `applications.commands` 권한을 꼭 체크해 주세요.
- **역할 순서:** '시민' 역할을 자동으로 주려면 봇의 역할 순위가 '시민'보다 위에 있어야 합니다.
